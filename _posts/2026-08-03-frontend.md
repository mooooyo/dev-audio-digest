# 2026-08-03 frontend 뉴스 정리
## Next.js 16.3.0 릴리즈
Next.js 16.3.0 버전이 릴리즈되었습니다. 주요 변경점은 다음과 같습니다.
- **보안 취약성 해결**: lodash 버전을 4.17.23으로 업데이트하여 CVE-2025-13465를 해결했습니다.
- **버그 수정**: 루트 레벨에서 RSC 요청시 올바른 HTML 응답을 반환하지 않는 문제를 해결했습니다.
- **Dynamic路由 처리 개선**: 앱 라우트에서 인코딩된 동적 플레이스ホル더를 정규화했습니다.
- **Turbopack 업데이트**: Turbopack의 스냅샷 로직을 개선하고 서버의 HMR을 활성화했습니다.
- **다른 버그 수정과 개선**: 다양한 버그를 수정하고 개선했습니다. ([원문](https://github.com/vercel/next.js/releases/tag/v16.3.0))
